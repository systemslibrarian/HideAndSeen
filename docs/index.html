00 / THESIS

Hidden is not the same as unfindable.

A QR code is not simply a URL represented by black squares. It is a stack of choices: segmentation, data codewords, padding, error correction, masks, modules, and sometimes structure below the scale an ordinary camera preserves.

Each layer can create alternate representations. Every hiding method also creates assumptions, tradeoffs, or artifacts. Understanding the cover format is what turns invisible information back into visible evidence.
