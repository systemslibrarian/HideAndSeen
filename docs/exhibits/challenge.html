THE FOUR QUESTIONS

Ask four questions before you choose a tool.

WHAT THE SCANNER SEES

One valid payload with no provenance, and no indication of which mechanism — if any — produced the symbol.

WHAT CHANGED UNDERNEATH

Unknown until you inspect. Each case draws on the mechanisms from exhibits 01-11, and some cases are genuinely clean.

WHAT A SECOND READER CAN RECOVER

Only if you check the layer the mechanism actually used. A padding reader recovers nothing from a segmentation case.

HOW AN ANALYST CAN NOTICE

Match the instrument to the layer. A clean result from one tool clears that layer only, and a regeneration difference on its own can still be an innocent encoder mismatch.

FINAL LESSON

There is no universal “steganography bit.”

Detection depends on knowing where alternate representations can exist, checking the right layer, and modeling innocent variation. A clean result from one tool does not clear every channel. A difference from one reference does not prove hidden data.

Understanding the cover format is what turns “invisible” information back into visible evidence.
